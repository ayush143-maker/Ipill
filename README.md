# 💊 Oops Atlas

> "Because apparently spreadsheets are more romantic than condoms."

Oops Atlas is a data visualization project that explores contraceptive awareness and emergency contraceptive usage trends across India using publicly available **NFHS-5** and **NFHS-6** datasets. The goal isn't to shame anyone—it's to present health data in a way that's actually interesting.

## 📊 Features

- 🗺️ Interactive India map
- 📈 State-wise comparisons
- 📉 NFHS-5 vs NFHS-6 trends
- 🎨 Clean dark UI
- ⚡ Fast and responsive
- 📱 Mobile friendly

## 📦 Data Source

All statistics are derived from publicly available **National Family Health Survey (NFHS-5 & NFHS-6)** reports. The website visualizes existing survey data only and does not collect or infer personal information. 0

## ⚠️ Disclaimer

This project is created for educational and data visualization purposes.

The visualizations do **not** represent real-time emergency contraceptive sales or individual behaviour. Correlation ≠ causation. Please don't write your sociology thesis after looking at one heatmap.

## 🛠️ Tech Stack

- HTML / CSS / JavaScript
- Leaflet.js
- Chart.js
- NFHS Dataset
